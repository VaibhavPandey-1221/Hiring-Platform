# NextHire – AI-Powered Recruitment Portal

NextHire is an AI-powered recruitment platform designed to simplify the job search and hiring process. It provides intelligent career guidance, resume analysis, recruiter dashboards, and secure premium features.

## 🚀 Features

- 🤖 **AI Career Guidance** – Personalized career recommendations.
- 📄 **Resume Analysis** – AI-powered resume evaluation and insights.
- 💼 **Recruiter Dashboard** – Manage jobs and candidates efficiently.
- ⚡ **Microservices Architecture** – Event-driven communication using Kafka.
- 🔴 **Redis** – Caching and efficient data processing.
- 📧 **Email Notifications** – Automated event-based notifications.
- 🔐 **Authentication & Password Recovery** – Secure account management.
- 💳 **Razorpay Subscriptions** – Premium plans and secure payments.
- 🗄️ **PostgreSQL** – Reliable relational data storage.

## 🛠️ Tech Stack

**Frontend:** Next.js  
**Backend:** Node.js, Express.js  
**Database:** PostgreSQL  
**Messaging:** Apache Kafka  
**Caching:** Redis  
**Payments:** Razorpay  
**Architecture:** Microservices

## 🏗️ Architecture

NextHire follows a **microservices-based, event-driven architecture**, where services communicate asynchronously through Apache Kafka, while Redis handles caching and performance optimization.

## 📌 Highlights

- AI-powered recruitment workflow
- Scalable microservices architecture
- Secure authentication and payments
- Event-driven notifications
- Recruiter and candidate-focused features
